Grammar Reference

4️⃣ ГЛАВНЫХ ПРАВИЛА:
1️⃣ is = один предмет (singular)
2️⃣ are = много предметов (plural)
3️⃣ some = в утвердительных предложениях
4️⃣ any = в вопросах и отрицаниях

ТипПримерПравило
Утверд. (1)There is a pilot.один = is
Утверд. (много)There are some passengers.много = are + some
Утверд. (неисч.)There is some fuel.топливо = is + some
Отриц. (1)There is not a doctor.один = is not
Отриц. (много)There are not any seats.много = are not any
Отриц. (неисч.)There is not any turbulence.неисч. = is not any
Вопрос (1)Is there a problem?один = is?
Вопрос (много)Are there any tickets?много = are any?
Вопрос (неисч.)Is there any coffee?неисч. = is any?
→ БЫСТРАЯ ШПАРГАЛКА:
Singular (1) → is/is not
Plural (много) → are/are not + some/any
Uncountable (неисч.) → is/is not + some/any
